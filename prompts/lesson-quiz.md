Quiz rules:
- Exactly 5 questions, each with 3 options and one clearly right answer.
- Ask "what would happen if…", "which of these is an example of…", "why does…"
  — never "what did the speaker say" or details only the video would know.
- Wrong options must be plausible misconceptions, not jokes.
- Build up: question 1 checks the basic idea, question 5 applies it to a new situation.
- "why": 1–2 sentences that teach, not just "because B is correct".
