Simulator rules (shows how a system works, one state at a time):
- "nodes": 3–8 parts of the system in the order work flows through them.
  Labels max 4 words. ids are short lowercase slugs.
- "states": 4–6 moments in one run of the system, in time order. Each has a
  label (max 6 words), "happening" (1–2 plain sentences on what is going on
  right now and why), and "highlight" = the id of the node doing the work.
- The run should tell a story from start to finish, e.g. one request travelling
  through and back. Revisiting a node is fine.
