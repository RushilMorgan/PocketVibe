Think through this scenario for someone at level {level}, plainly and honestly:
"{scenario}"
It comes from a save titled "{title}" (its content follows). They are into:
{top_topics}. Tone: {tone}.

This is speculation and should read like careful thinking, not hype.

Facts Search found about where things stand today:
{facts}

Return JSON:
- "today": the numbers of the 2–3 facts above that best show where things
  stand now. Use only those numbers; [] if none fit.
- "first_effects": 2–3 short lines on what changes in the first year or two.
- "knock_on": 2–3 short lines on second-order effects that follow from those —
  the less obvious ones.
- "winners" and "losers": 2–3 each (at least 1 loser). Name real kinds of
  players — companies, jobs, industries, countries — never "society".
- "timeline": "near", "medium" and "long", each with "when" (rough years, e.g.
  "2027–28") and "what" (one line).
- "likelihood": low, medium or high, and "likelihood_why": one honest line.
  Low is a fine answer.
- "signals": exactly 3 concrete, checkable signs it is actually happening — the
  kind of headline that would prove it (e.g. "A top-5 carmaker gives a price and
  launch date for a car using it"). Never vague ones like "more adoption".
- "alternatives": 2 other what-if questions on the same save, each starting
  "What if" — e.g. the opposite outcome, or a regulator or rival stepping in.

Rules: global view, not one country. One line means one sentence. No hype words
("revolutionise", "game-changer", "unprecedented"), no filler ("in today's
world"). Be specific: numbers and names beat adjectives.
